# Reporting a security issue

This is a synthetic research prototype. It must not be used to authorize payments.
See [the threat model](docs/THREAT_MODEL.md) and [security boundaries](docs/SECURITY.md).

Once hosted on GitHub, enable **Settings → Code security → Private vulnerability reporting**.
Use the repository's **Security → Report a vulnerability** form for sensitive findings.
If private reporting is unavailable, open an issue requesting a private contact route;
do not publish credentials, real payment data, or exploit details in that issue.

No support SLA or independent security certification is claimed. Application version 2.2
is the current portfolio revision; older evidence is retained for research provenance.
